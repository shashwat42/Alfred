# Alfred beta 7.6

- Removed the day/date pill from dashboard pages and Focus Session.
- Workspace cards and the dashboard Notes pill follow Alfred's charcoal and red theme.
- Android Focus Session returns to Workspace. On PC, Focus Session sits beside the notes input in the same horizontal row.
- Removed the Android bottom-navigation shadow beneath the notes input.
- Dashboard titles align horizontally with their navigation buttons.
- Focus transition timers are cancelled when leaving the component.

Windows x64 and Android ARM64 use **0.1.0-beta.7.6**. Android version code **1017** retains the existing release certificate for in-place upgrades. Keep your existing app data when updating. This release uses the existing beta 7 backend.

Test, lint, type and UI check suites were skipped for this release at the user's request. Packages use the existing Windows updater signing key and Android release certificate. Real-device installation, upgrade and appearance/interaction acceptance have not been performed. No Windows Authenticode certificate is configured.
