# Alfred 0.1.0-beta.2

Adds in-app updates to the Windows x64 beta.

- Alfred checks for newer published releases at startup and every six hours,
  including newer beta versions.
- Settings → App updates includes **Check for updates**, release notes and a
  **Download and install** button when a newer version is available.
- Downloads show progress. Failed checks and downloads show a retryable error.
- Updates are verified against Alfred's pinned signing key and signed version
  before the installer starts. Alfred restarts after installation.

## Install this version once

The original 0.1.0-beta.1 did not include an updater. Install
`Alfred_0.1.0-beta.2_windows_x64-setup.exe` manually once to enable future in-app
updates. Save your work before installing. Windows x64 and WebView2 are required.

Only published releases with signed update assets appear in the app. Drafts remain
hidden until published. Android and browser previews do not offer Windows updates.

## Known limitations

- Windows publisher signing is not configured, so Windows may show a reputation
  or publisher warning. The updater's verification signature is separate from
  Windows publisher signing.
- Offline or rate-limited GitHub requests can delay update detection; use
  **Check for updates** to retry later.
- A full install-and-restart acceptance pass still needs a separate Windows test
  profile or VM; it has not been run against the developer's installed app.

Report issues with the version, Windows version and reproduction steps. Remove
personal content and account tokens from screenshots or logs.
