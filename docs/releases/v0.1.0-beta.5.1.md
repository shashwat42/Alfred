# Alfred beta 5.1

- Android schedule reminders now use Firebase Cloud Messaging so the app does not need to stay open. Install this update and open Alfred once with notification permission and internet access to register the phone.
- Schedule time zones now detect the device zone automatically, including IST. A manually selected zone stays fixed.
- Fixed Android's “Open assistant setup” button by using supported public settings screens with fallbacks.
- PC receives automatic time-zone detection. Desktop reminders continue while Alfred is running, including in the system tray.

Firebase push uses the free Spark plan and Alfred's existing backend. It does not require Google Analytics or a paid Firebase plan. Android force-stop, notification permissions, internet connectivity, and device battery policies still affect delivery. Delayed reminders expire after two minutes. Real-device closed-app delivery still needs confirmation after installing this build.
