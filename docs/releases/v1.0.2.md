# Alfred 1.0.2

- Fixes blank settings dropdowns on Fedora by rendering readable dark controls in WebKitGTK.
- Adds a configurable global overlay keybind and first-run Linux shortcut setup.
- Fedora/Wayland requests shortcut approval through the desktop GlobalShortcuts portal and displays the binding actually granted.
- Supports changing or disabling the binding, deferring setup, and opening Keyboard settings when the portal is unavailable.
- Preserves the working Windows/X11 binding when a replacement conflicts, and restores enabled shortcuts after restart.

Keep Alfred running or minimized for the portal shortcut. Closing the main Linux
window quits the app. Choose a keybind and approve the desktop dialog at first
launch, or use Settings → Global overlay shortcut later.

Windows x64 and Fedora Linux x86_64 packages are built from this release source.
Android users retain the existing signed 1.0.0 APK. Automated tests cover native
validation, controller state, setup/cancellation and UI rendering. Physical
shortcut approval requires user interaction.
