# Alfred 1.1.1

Session recovery now opens with a centered, larger Alfred logo, a Retry button
and a **Login Again** link. Login Again opens a second stage with guest and
Google sign-in choices and a link back to recovery. Recovery stays visible while
retrying or signing in, with inline feedback for failed actions.

The offline and server-unavailable screens use the same centered layout, with
**Try again** as the primary action and **Continue with saved content** as a text
link. The previous description and redundant session-expiry toast are removed.
Saved content, drafts and existing account recovery behavior are preserved.

Windows x64, Fedora Linux x86_64 and Android ARM64 use version 1.1.1 from the
same source commit. Android version code is 1028 and retains the 1.1.0 signing
certificate for compatible in-place updates. Windows and Linux retain their
existing updater signing identities.
