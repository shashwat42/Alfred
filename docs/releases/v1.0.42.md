# Alfred 1.0.42

- Choose **Notification** or **Alarm** under **Settings → Schedule Notifications → Alert type**. The choice syncs across Windows, Fedora Linux and Android through your Alfred account. An alarm repeats a tone and can be dismissed on the receiving device.
- On Windows and Fedora, **Launch on startup** starts Alfred in the background at sign-in. Open it from the tray or app launcher. Alfred updates existing startup entries the first time you run this version.
- Android uses version code 1026. Install this certificate-aware build from GitHub to enable discovery of future updates signed with the same certificate.

Schedule alarms use the existing Cloud Sync reminder service and require the updated backend.
