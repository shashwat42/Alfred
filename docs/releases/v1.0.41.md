# Alfred 1.0.41

This release carries forward the device-management fixes from 1.0.4 under a version that both 1.0.31 and 1.0.4 recognize as newer.

- On Windows and Linux, use the pencil to rename a device under **Settings → Schedule Notifications → Reminder device**.
- Use the trash button to sign out that device and remove it from the list. An offline device signs out when it reconnects.

Windows x64 and Fedora x86_64 can use their signed desktop updaters. The Android ARM64 APK uses version code 1025 and the same certificate as 1.0.31 and 1.0.4. Download and install the APK over either version. Android 1.0.0 and older use a different certificate and require uninstalling first, which removes local-only data.
