# Alfred 1.1.0

Windows x64, Fedora Linux x86_64 and Android ARM64 ship from the same source
commit with version 1.1.0. Frontend, backend, npm lockfiles, Tauri and Cargo
versions are checked together before builds and release packaging. Android uses
version code 1027. All release builds use the same production API origin.

Signing out now revokes only that device's credential, including when cloud sync
is disabled. Other devices stay signed in and their pending Google sign-ins
remain valid. A signed-out device cannot renew its guest token or complete its
pending Google sign-in. Account session-revocation counters remain independent
of application versions, preserving existing valid sessions across upgrades.

## Android signing transition

This release uses a new Android signing certificate. Android cannot install it
over an APK signed with the previous key. Export any local data before removing
the old app, then install this APK manually and sign in again. Uninstalling can
erase local-only data. Certificate-aware old clients intentionally do not offer
this APK as an in-place update. Future releases will reuse this new key.

Windows and Linux retain their existing signed updater identities. Older public
releases are archived as drafts after 1.1.0 is published to avoid accidental
installation of Android packages with the retired signing identity.

## Validation

Release checks include frontend tests, lint, TypeScript/build checks, isolated
backend integration tests, desktop native checks and Android release compilation.
Physical-device installation, manual sign-in and upgrade acceptance require
real-device verification.
