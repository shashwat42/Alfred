# Alfred beta 7

- Voice pause, Quick Input/Voice mode, sidebar state and Windows startup preferences belong to your account. Enable Cloud Sync to share preferences across PC and Android. Existing device preferences migrate once without being inherited by another account; OS permission grants remain managed on each device.
- Profile photos are cropped to **512 × 512** and compressed below **200 KB**, with compression retries and clearer errors. The top-right refresh also updates account information in the PC chat area, usage and preferences.
- Settings use toggle switches and more compact sections. Profile editing and secondary help expand when needed. Cloud Sync explains that it is needed for cross-platform usage, and Android includes the Quick Input/Voice preference.
- Android omits the branding header, accounts for keyboard/system insets, and returns through previously viewed screens on Back. Notes save before leaving; failed saves keep the editor open. Finishing or skipping the tutorial returns to Dashboard.
- Focus Session and day/date controls are inside Dashboard content. The welcome screen is more compact on smaller displays. Long press reveals item details, with keyboard equivalents and visual cues for empty tasks, notes and schedules.
- Notes hide the mobile navbar while editing. Formatting starts collapsed, preserves the selection, has a copy-content action and uses a transparent background. Quick Note also has no pill background. Three-line previews and copied text preserve rich-text paragraph boundaries.
- Floating assistant logos remain static while microphone waveforms react to measured input. Overlay positioning and opening transitions reduce flicker; animations respect reduced-motion preferences. Android assistant setup can still be opened when its status lookup fails.
- Offline and server-unavailable screens offer recovery without discarding drafts. Saved cloud content remains readable during outages, while cloud writes are not silently converted to local-only changes. The shared loader uses a buttoning-up tuxedo animation; the 404 view remains available.

## Windows and Android

Windows x64 and Android ARM64 use **0.1.0-beta.7**. Android version code **1011** retains the existing release certificate for in-place upgrades. Keep your existing app data when updating. Android 7.0/API 24 or newer is supported; system-assistant integration requires Android 12 or newer.

Cloud Sync remains off for accounts that have not enabled it. Backend and app updates ship together because account preference synchronization uses new authenticated endpoints.

Validation includes development-mode isolated frontend/backend and UI tests, small-screen and desktop browser checks, native debug compilation/unit tests, and release package/signature/checksum checks. Real-device installation, upgrade, native Back/keyboard behavior, microphone/assistant operation and end-to-end self-update acceptance have not been performed. Windows installers have an updater signature; no Windows Authenticode certificate is configured.
