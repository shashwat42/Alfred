# Alfred 0.1.0-beta.1

First Windows beta of Alfred, an AI desktop assistant for notes, tasks, schedules,
text chat and voice interactions.

- Windows x64 installer with desktop overlay and system tray integration.
- Continue as a guest or sign in with Google.
- Notes, tasks and schedules with assistant tools and schedule notifications.
- Voice recording and conversation, with configurable speech pause detection.
- Account usage, session recovery and actionable error messages.

## Install

Download `Alfred_0.1.0-beta.1_windows_x64-setup.exe` and run it on a Windows x64
computer with Microsoft Edge WebView2. The installer can provision WebView2 if
needed, which requires internet access. Internet access is also required for
sign-in, saved content and AI requests.

The beta uses the hosted Alfred backend. This release is an early test version;
keep copies of important content. AI requests and storage are subject to the
service's account limits.

## Known limitations and testing status

- Windows code signing is not configured. This unsigned beta may show Windows
  reputation or publisher warnings. Verify the download source and SHA-256 checksum.
- No automatic updater is configured. Install a later beta manually.
- Schedule notifications require Alfred to be running and Windows notifications
  to be enabled; reminders are not guaranteed while Alfred is closed.
- Google OAuth, microphone access, notifications and upgrade behavior still need
  a manual acceptance pass on a separate Windows test profile or VM.
- Android, macOS, Linux and Windows ARM64 packages are outside this release.
