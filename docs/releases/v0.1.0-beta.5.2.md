# Alfred beta 5.2

- Redesigned Android and PC assistant overlays with black rounded pills, white circular mode controls, and red microphone/send accents.
- Voice overlays show a recording waveform and a thinking animation during processing. The microphone control turns recording on or off; the circular cross switches to text mode.
- PC overlays have a circular clear-chat button in both modes and clear the conversation after one minute of inactivity. Use Alt+Space or the tray overlay action to toggle visibility; Escape still dismisses the overlay.
- Added an optional Windows **Launch on startup** setting, disabled by default.
- Android schedule notifications now use a transparent monochrome Alfred logo in the status bar.

Includes signed Windows x64 updater assets and an Android ARM64 release APK using the existing Android signing certificate (version code 1008).

Validation uses development-mode automated tests with isolated data and stub AI providers, plus native compilation and release package/signature checks. Live-device appearance, installation/upgrade, Windows startup at sign-in, and end-to-end self-update still need device acceptance.
