# Alfred beta 8

- Desktop dashboard titles are left aligned with stable navigation and action placement; desktop back buttons are removed.
- Desktop dashboard spacing is improved, and the Notes and Focus Session pills share a height.
- Android page titles are left aligned, with Back beside Refresh on Workspace and Settings. The dashboard Notes pill has added space below it.
- Selecting Assistant on Android expands the chat panel even when the desktop sidebar was saved as collapsed.

Windows x64 and Android ARM64 use **0.1.0-beta.8**. Android version code **1018** preserves in-place upgrades when signed with the existing release certificate. Keep your existing app data when updating. This release uses the existing beta 7 backend.

Development validation and release packaging are pending. Android device installation, upgrade and appearance/interaction acceptance have not been performed. No Windows Authenticode certificate is configured.
