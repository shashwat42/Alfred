# Alfred beta 6.1

- Android: long recently viewed note titles wrap to two lines inside their cards. Long words stay within the card too.
- Cloud Sync is an account-wide preference. Devices check the account setting after sign-in, on foreground return or reconnection, and once per minute while visible and online. Offline devices retain their last saved setting until they reconnect.
- A device joining an account that already enabled Cloud Sync merges its saved content with the cloud workspace. Failed uploads remain safely on the device, separately from cloud read caches, and can be retried automatically or through **Sync this device’s saved content** in Cloud storage.
- Disabling sync affects the entire account. The initiating device downloads the final workspace before cloud deletion; other devices retain their existing device copies. Concurrent changes cannot silently re-enable sync or discard pending local content.
- The private admin monitor is deployed separately at the backend's `/monitor` address. This app update includes foreground-only account presence reporting.

## Windows and Android

Windows x64 and Android ARM64 use version **0.1.0-beta.6.1**. Android version code **1010** and the existing release certificate support in-place upgrades from Beta 6 without clearing app data. Android 7.0/API 24 or newer is supported; system-assistant integration requires Android 12 or newer.

Keep your existing app data when upgrading. Cloud Sync is off for accounts that have not enabled it. Upgraded devices follow the existing preference for their signed-in account; older app versions need this patch for automatic preference refresh.

Validation includes development-mode isolated frontend/backend and UI tests, native compilation and release package, checksum and signature checks. Real-device installation, upgrade, microphone/assistant operation and end-to-end self-update acceptance have not been performed. Windows installers carry an updater signature; no Windows Authenticode certificate is configured.
