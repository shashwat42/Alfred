# Alfred 1.0.0

Alfred 1.0.0 is the first official stable release. Beta testing is complete.

- Tasks, notes, schedules and focused workspaces with local storage and optional Cloud Sync.
- Text and voice assistance, reminders, and Windows tray and overlay controls.
- Google sign-in with guest workspace merging, account preferences and fresh guest sessions after logout.
- Android assistant setup, responsive navigation and notification controls.
- Signed Windows in-app updates and a signed Android ARM64 APK.

Windows x64 and Android ARM64 use **1.0.0**. Android version code **1022** retains the existing release certificate for in-place upgrades. The existing deployed backend remains compatible.

Android beta installations validate only beta version names in their update checker. Download the 1.0.0 APK from this release and open it to upgrade in place; 1.0.0 supports stable versions in future update checks.

Automated validation runs in development mode with isolated databases and stub providers. Release packages are checked separately for source provenance, checksums and updater/APK signatures. No Windows Authenticode certificate is configured.
