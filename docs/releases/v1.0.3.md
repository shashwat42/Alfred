# Alfred 1.0.3

- Linux **Check for updates** can download verified RPM updates and install them
  through Fedora's PackageKit authorization flow.
- Updates verify architecture, package identity, size, checksum, signature and
  signed version. Cancellation or failed installation does not report success;
  Alfred restarts only after PackageKit confirms completion.
- Linux release tooling produces signed updater assets using the existing
  protected signing key.
- Includes the configurable global overlay keybind and Fedora/Wayland permission
  setup from the 1.0.2 development build, plus readable dark settings dropdowns.

Linux 1.0.1 and 1.0.2 installations require one manual upgrade to this build.
Subsequent in-app updates require a newer published release containing its signed
Linux updater assets. This does not retrofit the updater into an old executable.

Windows keeps its signed in-app updater. Android retains its existing separate
release. Linux desktop authorization and physical upgrade acceptance require
user interaction; automated tests use isolated installer fixtures.
