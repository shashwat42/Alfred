# Alfred 0.1.0-beta.5

Beta 5 is available for Windows x64 and Android ARM64.

- Fixed note autosave jumping to the start of the note. Saving preserves the editor, cursor and scroll position, retains typing made during a save, and serializes saves so new drafts reuse their saved ID.
- Fixed Android notification permission handling: Alfred waits for the permission result and immediately refreshes native reminder scheduling. The schedule notification channel is available when the app opens.
- Fixed **Open Alfred app** in the Android assistant panel. The normal app opens in its own task and stays available after the assistant session closes. Launch errors keep a retry available.
- Includes the Android beta 4.1 notification settings layout, APK update checks and assistant setup improvements.

## Downloads and updates

- Windows: `Alfred_0.1.0-beta.5_windows_x64-setup.exe`. Existing updater-enabled installations can discover this beta through App updates.
- Android: `Alfred_0.1.0-beta.5_android_arm64-v8a.apk`, version code `1006`. Uses the existing release certificate for in-place upgrades from beta 4 and beta 4.1. Download the APK and open it to install.
- Android requires Android 7.0/API 24 or newer; the system assistant requires Android 12 or newer.
- Checksums and source manifests accompany both downloads. Windows uses the existing updater signing key; Windows publisher signing remains unconfigured.

## Validation and limits

Development validation includes 49 frontend tests, autosave cursor/scroll and concurrent-edit regressions, Android settings interactions, TypeScript and targeted ESLint checks, and Android Kotlin compilation with 10 native unit tests.

Release artifacts are checked for versions, signatures, checksums and updater metadata. Android packaging is checked for the release certificate, ARM64 architecture, HTTPS API configuration and 16 KB alignment.

Physical-device notification delivery, opening the app from the assistant, Windows installation/self-update, and Android install/upgrade have not been accepted on live devices for this release. Android battery restrictions, permission settings and internet access still affect reminder delivery.
