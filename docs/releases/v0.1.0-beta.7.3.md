# Alfred beta 7.3

- Android has a compact Alfred header matching the current page surface, with native system-bar spacing to keep the day/date pill clear of the notification area. The voice-state pill returns at the top of Assistant while voice mode is active.
- Android Assistant no longer shows a sync button. Dashboard Settings remains in the bottom navbar, and the dashboard sync control has the same dimensions on every page.
- Android keyboard layout uses the actual WebView bounds and keyboard overlap rather than subtracting keyboard height twice. Hidden navigation no longer reserves an empty strip while editing notes or using the keyboard.
- PC note previews and gallery cards are taller. Quick Note has a visible input field, and its Notes pill and the Formatting button use a warmer accent color.

Windows x64 and Android ARM64 use **0.1.0-beta.7.3**. Android version code **1014** retains the existing release certificate for in-place upgrades. Keep your existing app data when updating. This release uses the existing beta 7 backend.

Validation includes development-mode frontend/backend and workspace interaction checks, 20 Android debug tests, native updater tests, and release package, signature and checksum verification. Real-device installation, upgrade and native appearance/interaction acceptance have not been performed. Windows has an updater signature; no Windows Authenticode certificate is configured.
