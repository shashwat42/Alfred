# Alfred beta 6

- Tasks, notes and schedules are stored on your device by default. Local edits work without a network request; AI still needs internet access.
- Enable **Settings → Cloud storage → Cloud Sync** to upload your workspace to Atlas and access it from other devices. The existing limit is now labelled **Cloud storage**.
- Turning Cloud Sync off saves a device copy before clearing the account's cloud workspace. Failed uploads, full device storage and concurrent cloud changes preserve data instead of silently switching modes.
- Edit your account name and add, replace or remove a profile photo in Settings. Google sign-in starts with your Google name and photo; guests start as **Guest**. Custom photos are cropped and resized on the device. Profile edits stay local unless Cloud Sync is enabled; uploaded profiles count towards cloud storage usage.
- Local AI tool actions use request-scoped memory and save their results back to the originating device. Account, session/security and AI-usage metadata remain online.
- Cloud reminders, Android background alarms and push delivery require Cloud Sync. Local mode does not upload schedules or register cloud reminders.

## Windows and Android

Windows x64 includes a version-bound updater signature, checksums and build provenance. Android ARM64 uses version code **1009** and the existing release signing certificate for in-place upgrades. Android 7.0/API 24 or newer is supported; Android system-assistant integration requires Android 12 or newer.

The hosted test database was reset before this beta. Existing test credentials may require a new guest account or another Google sign-in. Clearing device storage or uninstalling can remove local content; retain local data when upgrading.

Validation uses development-mode automated frontend/backend and UI tests with isolated databases and stub AI providers, plus native compilation and release package/signature checks. Real-device installation, upgrades, microphone/assistant operation and end-to-end self-update still require device acceptance. Windows installers have an updater signature but no configured Windows Authenticode certificate.
