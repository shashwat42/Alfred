# Alfred beta 7.4

- Tasks and schedules have visible edit controls in their lists and on the dashboard. Edit task text and priority, or change a schedule's topic, date and time without creating duplicates. Moving an event updates both day views.
- Notes have visible edit buttons, and formatting opens as a toggleable right sidebar on Android and PC. Close it with its header control or Escape.
- Dashboard buttons collapse into a burger menu when the dashboard panel becomes narrow, including split desktop windows. The menu supports outside clicks, Escape and Android Back.
- Quick Note floats as a compact pill without a reserved grey footer. Android has a larger header logo and tighter capture spacing.
- Android Focus Session is in Workspace, with remaining time shown for a running session.

Windows x64 and Android ARM64 use **0.1.0-beta.7.4**. Android version code **1015** retains the existing release certificate for in-place upgrades. Keep your existing app data when updating. This release uses the existing beta 7 backend.

Validation includes development-mode frontend/backend and workspace interaction checks, Android debug tests, native updater tests, and release package, signature and checksum verification. Real-device installation, upgrade and native appearance/interaction acceptance have not been performed. Windows has an updater signature; no Windows Authenticode certificate is configured.
