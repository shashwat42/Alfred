# Alfred 1.0.01

Alfred now supports Fedora Linux alongside Windows.

- Native Fedora RPM with an application launcher and Quick Overlay action.
- Linux microphone consent, launch-on-login settings and desktop notifications.
- Wayland overlay access through `alfred --overlay`, suitable for a custom desktop shortcut. X11 retains automatic Alt+Space registration where available.
- Linux closes the application when its main window is closed, avoiding an inaccessible background window on desktops without tray icons. Minimize to keep reminders active.
- Backend support for the exact Linux application origin, while preserving existing Windows and Android origins.
- Includes the account, profile and guest-session fixes from the published 1.0.0 release.

The public release title is **Alfred 1.0.01**. Packages, updater metadata and the
Git tag use the equivalent valid semantic version **1.0.1** / **v1.0.1**.

This update packages Windows x64 and Fedora Linux x86_64. Android users continue
to use the existing signed 1.0.0 APK; this release does not replace it.
The matching backend must be deployed before Linux clients use the hosted API.

See the [Fedora setup guide](../linux-fedora.md) for prerequisites, installation,
GNOME shortcuts and desktop limitations. Linux updates use RPM installation;
Windows uses the existing signed in-app updater. Windows Authenticode and RPM
package signing are not configured. Updater signatures are separate.

Automated builds and tests validate source, configuration and packages. They do
not replace physical desktop checks for voice, notifications, OAuth or Wayland
focus behavior.
