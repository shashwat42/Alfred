# Alfred beta 9.2

- Made Save profile a left-aligned red button and removed the photo preview from Edit Profile. Account photos remain visible in the account section and sidebar.
- Google sign-in merges the current guest's tasks, notes and schedules using the existing merge rules while retaining the Google account's existing data.
- Fixed merging into a Google account that already has Cloud Sync enabled: guest records remain pending until uploaded, even if a cloud read refreshes the local cache first. Sign-in preserves the existing Cloud Sync choice.
- Logout starts and confirms a fresh, empty guest session. Repeated sign-in/logout cycles merge each new guest's data into Google without returning to an earlier guest workspace.
- Added protections for duplicate logout clicks, failed session creation and delayed Google sign-in responses.

Windows x64 and Android ARM64 use **0.1.0-beta.9.2**. Android version code **1021** retains the existing release certificate for in-place upgrades. This release uses the already deployed beta 9 backend.

Automated checks run in development mode with isolated storage, databases and provider fixtures. Release packaging and signature checks are separate. Windows clean-install/upgrade acceptance and Android real-device installation, upgrade and appearance checks have not been performed. No Windows Authenticode certificate is configured.
