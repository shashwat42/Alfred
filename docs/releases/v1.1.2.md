# Alfred 1.1.2

- Loading now uses a centered white bow tie with fold lines and a defined knot,
  replacing the tuxedo and visible loading text. The transparent loader maintains
  a steady base rotation, briefly spins faster, then returns to the base speed
  without stopping. Reduced-motion preferences disable its animation.
- Android's floating assistant no longer has an Options button or menu. The logo
  in voice mode is decorative. Text/voice switching, microphone controls and
  tapping outside the dock to dismiss remain available.
- App and development-preview toast notifications appear at the top center on
  Windows, Fedora Linux and Android, with responsive mobile spacing.

Windows x64, Fedora Linux x86_64 and Android ARM64 ship from the same source
commit with version 1.1.2. Android uses version code 1029 and retains the existing
1.1.0 signing certificate. Windows and Linux retain their updater signing keys.
