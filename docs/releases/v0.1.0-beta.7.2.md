# Alfred beta 7.2

- Page titles and navigation stay anchored while workspace content scrolls. Day/date and Focus Session remain in the same position across dashboard pages, and Home opens the dashboard.
- An empty dashboard shows one shared text-art face with “Nothing to show here :)”. When content exists, individual empty sections use different faces in the same style. Unopened notes still count as content.
- Mobile navigation now has four destinations: Assistant, Dashboard, Workspace and Settings. Workspace opens Schedule, Tasks and Notes, remains selected on those pages, and participates in swipe and Back navigation. The navbar remains hidden while editing a note.

Windows x64 and Android ARM64 use **0.1.0-beta.7.2**. Android version code **1013** retains the existing release certificate for in-place upgrades. Keep your existing app data when updating. This release uses the existing beta 7 backend.

Validation includes development-mode frontend, backend and workspace interaction checks, native updater tests, and release package, signature and checksum verification. Real-device installation, upgrade and native layout/interaction acceptance have not been performed. Windows has an updater signature; no Windows Authenticode certificate is configured.
