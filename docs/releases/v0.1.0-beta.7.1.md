# Alfred beta 7.1

- Upcoming and its navigation buttons now appear below the day/date and Focus Session row. The row no longer has a separate background panel.
- Empty schedules and tasks use centered text-art faces instead of checkbox or calendar illustrations.
- Quick Note has a colored notes-label pill with a transparent surrounding area. Formatting has its own colored pill button and still expands only when clicked.

Windows x64 and Android ARM64 use **0.1.0-beta.7.1**. Android version code **1012** retains the existing release certificate for in-place upgrades. Keep your existing app data when updating.

Validation includes development-mode frontend and workspace interaction checks, plus release package, signature and checksum verification. Real-device installation, upgrade and native interaction acceptance have not been performed. Windows has an updater signature; no Windows Authenticode certificate is configured.
