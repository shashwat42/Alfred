# Alfred 1.0.4

- On Windows and Linux, use the pencil to rename a device in **Settings → Schedule Notifications → Reminder device**.
- Use the trash button to sign out that device and remove it from the list. Other devices stay signed in. An offline device signs out when it reconnects.

## Installation

- **Windows x64** and **Fedora x86_64**. Download the 1.0.4 installer from GitHub if you are on 1.0.31. The earlier build has a higher version number, so its in-app updater skips 1.0.4. On Fedora, use `sudo dnf downgrade ./Alfred-1.0.4-1.x86_64.rpm` to replace 1.0.31 with this RPM.
- **Android ARM64**. Download the APK from GitHub. Android version code 1024 and the same signing certificate support installing over 1.0.31. Android 1.0.0 and older use a different certificate and require uninstalling first, which removes local-only data.
