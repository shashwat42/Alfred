# Alfred beta 7.5

- Dashboard previews no longer show edit buttons. Task, schedule and note editing stays on the respective pages; recently viewed notes still open with a tap.
- Android headers show the sync button alongside the page title, without a burger menu. Desktop retains its responsive navigation menu.
- Note formatting uses a narrow, single-column vertical toolbar. When the editor is too short to fit every control, a three-dot button opens the remaining controls. Font sizes open in a separate vertical picker; Escape dismisses the picker or overflow before closing formatting.
- The dashboard's notes pill sits just above Android's bottom navigation. Its spacing follows the actual navigation height and avoids counting the system inset twice.

Windows x64 and Android ARM64 use **0.1.0-beta.7.5**. Android version code **1016** retains the existing release certificate for in-place upgrades. Keep your existing app data when updating. This release uses the existing beta 7 backend.

Validation includes development-mode frontend/backend and workspace interaction checks, Android debug tests, native updater tests, and release package, signature and checksum verification. Real-device installation, upgrade and native appearance/interaction acceptance have not been performed. Windows has an updater signature; no Windows Authenticode certificate is configured.
