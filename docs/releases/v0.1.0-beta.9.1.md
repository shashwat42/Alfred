# Alfred beta 9.1

- Removed custom profile photo upload and removal controls. Settings and the sidebar use the signed-in Google account photo; guests and accounts without a photo use the existing fallback. Saved custom photos no longer override Google photos. Account name editing remains available.
- Added desktop top clearance below the minimize, maximize and close buttons.
- Centered the Android welcome card within the safe viewport, with scrolling on smaller screens.
- Changed Android assistant setup to open Default apps settings, with voice-input and general Settings fallbacks. Added setup guidance, retryable errors and status refresh when returning to Alfred.
- Matched the notes formatting sidebar, menus, toggle and interaction states to Alfred's charcoal and red theme.

Windows x64 and Android ARM64 use **0.1.0-beta.9.1**. Android version code **1020** retains the existing release certificate for in-place upgrades. This release uses the already deployed beta 9 backend.

Automated checks run in development mode with isolated storage, databases and provider fixtures. Release packaging and signature checks are separate. Windows clean-install/upgrade acceptance and Android real-device installation, upgrade, layout and assistant-settings acceptance have not been performed. No Windows Authenticode certificate is configured.
