# Alfred beta 9

- Added desktop top and bottom spacing and kept page titles at the same left-aligned position across Upcoming, Schedule, Notes, Tasks, Workspace and Settings.
- Moved desktop page actions below the shared title and navigation row.
- Show ASCII artwork only when schedules, tasks and notes are all empty. Otherwise empty sections use simple text, including when existing content is outside the dashboard's filters.
- Added space between Android's floating notes pill and bottom navigation.
- Removed back buttons from Android navbar destinations while keeping back navigation on nested pages.
- Added an authenticated, account-scoped all-dates schedule query so cloud-backed empty states include events outside today.

Windows x64 and Android ARM64 use **0.1.0-beta.9**. Android version code **1019** retains the existing release certificate for in-place upgrades. This release requires the matching beta 9 backend schedule query.

Development validation and signed release packaging are performed separately. Windows clean-install/upgrade acceptance and Android real-device installation, upgrade and appearance checks have not been performed. The browser preview could not reach the local development server. No Windows Authenticode certificate is configured.
